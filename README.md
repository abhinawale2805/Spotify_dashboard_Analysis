A visually engaging Spotify Analytics Dashboard built in Microsoft Power BI to explore music data, artists, albums, and song trends.
This dashboard provides interactive insights with a Spotify-inspired theme and navigation experience.

📌 Dashboard Preview

🚀 Project Overview

This Power BI project is designed to analyze Spotify music data and present insights through an interactive dashboard interface.

The report includes:

Music overview statistics

Artist-wise analysis

Song performance trends

Album-level exploration

Smooth navigation buttons for user interaction

✨ Key Features

🎧 Spotify-themed dashboard design

📊 Interactive report pages (Home, Overview, Artists, Songs)

🔍 Drill-through and filtering capabilities

📈 Trend analysis using charts and KPIs

🎨 Clean UI with dark mode + Spotify green branding

🛠️ Tools & Technologies Used

Microsoft Power BI

Power Query (Data Cleaning & Transformation)

DAX Measures (Calculations & KPIs)

Data Visualization Techniques
